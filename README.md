# Statistical-Methods-and-R

Project Goal:

The aim of this project was to practice basic statistical methods using the R programming language. Three separate reports were written, one for each of three publicly-available datasets. The reports included data visualisations and statistical analyses.

Key Findings:

Report 1 - Year of study is independent of therapy status, but employment status and gender are not.

Report 2 - Brain size in hominids may not always increase with cognitive ability.

Report 3 - GPA scores differ between ethnic groups that are not underrepresented in third-level education and ethnic groups that are underrepresented. Sleep time does not differ.

Outputs:

All charts, summaries, tables, etc. can be viewed in [Project](docs/Project.pdf) 

How to Run:
1. Download or clone this repository to your computer.
2. Open RStudio and install the required packages:
   

4. Open [`src/Project.R`](src/Project.R) and run the script from top to bottom.
